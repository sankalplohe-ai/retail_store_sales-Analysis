# Retail Store Sales Analysis | Python, Pandas & Regression Modeling

End-to-end data cleaning, exploratory data analysis, and revenue forecasting on retail sales data using Python.

## Key Results

- **Dataset size:** 10,000+ sales records
- **Key outcomes:** Uncovered revenue trends and seasonal patterns
- **Model:** Cross-validated regression models built to forecast revenue

## Project Overview

This project analyzes retail sales data to surface actionable insights on revenue and seasonality, then builds regression models to forecast future revenue trends.

## Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Regression Model Building
6. Cross-Validation
7. Revenue Forecasting & Evaluation

## Evaluation Metrics Used

- Cross-Validation Score
- R² Score
- Error Metrics (MAE / RMSE)

## Conclusion

This project demonstrates a complete data analysis and forecasting workflow — from raw retail sales data to a cross-validated regression model — for predicting revenue trends.
